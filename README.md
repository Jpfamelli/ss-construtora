# SS Construtora

Site da SS Construções e Reformas: construção, reforma e áreas de lazer em Mogi das Cruzes e região.

- No ar: https://ss-construtora-mogi.netlify.app
- Espelho: https://jpfamelli.github.io/ss-construtora/

Site estático (HTML, CSS e JS puro, sem build). Para rodar local, sirva a pasta com qualquer servidor estático:
`npx http-server . -p 4950 -c-1` e abra http://localhost:4950.
